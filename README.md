This repository contains the R code and supplementary tables from my PhD project titled 'Bone marrow adiposity as novel determinant of type 2 diabetes: a UK Biobank study'. Everything is ordered according to the sequence of chapters in the PhD thesis document (available through the Edinburgh Research Archive: https://hdl.handle.net/1842/15818). Only summary-level data are made available in accordance to the UK-Biobank's protecting participant confidentiality legal agreement. The original code for sorting UK-Biobank abdominal MRI data and generating fat fraction maps (including the creation of whole-body fat fraction maps reported in the current thesis) are available here: https://github.com/WillCawthorn/OPTIMAT. 

Descriptions of the files listed herein are provided below. The first sheet of each .xlsx file contains a brief description of each supplementary table. 

* PhD_code_final.Rmd: contains the code required to replicate the analyses conducted in this PhD project, organised in order of chapters 3-6 of the thesis (see description at the top of the document for more details).
* Thesis_chapter_1_supplementary_table: supplementary table from chapter 1 ('Background and literature review').
* Thesis_chapter_3_supplementary_tables: supplementary tables from chapter 3 ('Processing and characterization of bone marrow fat fraction measurements').
* Thesis_chapter_4_supplementary_tables: supplementary tables from chapter 4 ('Bone marrow adiposity distribution as an associate and predictor of type 2 diabetes').
* Thesis_chapter_4_PC2_PheWAS_supplementary_tables: supplementary tables from the PC2 PheWAS analyses in chapter 4.
* Thesis_chapter_4_spine_BMFF_PheWAS_supplementary_tables: supplementary tables from the spine BMFF PheWAS analyses in chapter 4.
* Thesis_chapter_5_supplementary_tables: supplementary tables from chapter 5 ('Genome-wide association studies and genetic instrumentalization of bone marrow adiposity distribution').
* Thesis_chapter_6_supplementary_tables: supplementary tables from chapter 6 ('Assessing the casual implications of bone marrow adiposity distribution for T2D').
